# Mechanical files

- `OpenWatts_RevA_Assembly.step` is the populated PCB assembly exported from
  KiCad.
- `OpenWatts_RevA_Enclosure.step` is the reduced KiCad board/connector reference
  that was used while designing the case. Despite the old filename, it is not
  the enclosure shell.
- `OpenWatts_RevA_Enclosed_Assembly.step` is the Fusion export of the final-fit
  case with the OpenWatts PCB assembly installed inside it.
- `OW Case.3mf` is the existing printable case file.
